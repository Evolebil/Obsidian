При создании пустого класса формы создаёться 3 файла:
1. файл с исходным кодом класса(для MainWindow это будет mainwindow.cpp)
2. заголовочный файл(mainwindow.h или mainwindow.hpp)
3. файл интерфейса(mainwindow.ui) - XML файл с расширением .ui

Имя каждого файла зависит от настроек проекта. По умолчанию используеться имя класса без ригистра

Как и в обычном языке С и С++ основным компилируемым файлом являеться main.cpp который не имеет ui файлов и не являеться заголовочным.

Чтобы создать окно необходимо в main.cpp подключить заголовочный файл окна и создать переменную с типом класса окна

При создании класса формы создаёться новый указатель с именем ui который хранит информациюоб элементах интерфейса
при создании формы вызываеться метод(внутри класса) setupUI(this) который. записывает и инициализирует информацию об интерфейсе. 
 в деструктуре класса формы(~"ИмяКлассаФормы") указатель на ui удаляеться

У каждого элемента интерфейса есть свои собственные слоты. 
Слоты - функции с типом данных void которые сегнализируют о каком-то событии(например если нажата кнопка) или курсор находиться в определённой облости
