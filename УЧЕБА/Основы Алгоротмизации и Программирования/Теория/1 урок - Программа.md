==**ПРограмма**== - набор инструкций для компьютора необходимый для решения определнной задачи.
Программы создаються с помощью языка программирования.
Языки программирования бывают:
1. ==**Компелируемые**== - файл с исходным кодом проходит процесс компеляции превращая инструкции написанные на понятном человеку языке в машинный код
2. ==**Интерпритируемые**== - программа-интепритатор выполняет код из исходного файла построчно или по этапно, позволяя проводить анализ кода
Основные элементы кода программ:
* Переменные - именновое область памяти компьютора преназначная для хранения данных
* Тип данных - определённая константа которая говорит компьтору сколько байт необходимо выделить под ту или иную переменную
* Операторы - специальные команды в языке программирования сокращённые до 1 знака и выполняющие определённуюю математическую или логическую фунцию
* Условные конструкции - специальные конструкции в языке программирования которые позволяют выполнять определённые действия в зависимости от результата условия (логического выражения)
* Циклы - специальные конструкции в языке программирования которые позволяют повторять определённого условия(логического вырожения)
* Функции - именновые участки кода предназначенные для решениея определённой задачи 
* Классы - специальные шаблоны позволяющие создовать свои типы данных имеющие параметры(атрибуты) и методы(функции)
* ОБЬЕКТЫ - НУ ГДЕ ЖЕ РУЧКИ НУГДЕ ЖЕ НАШИ РУЧКИ - это элименты кода созданные как переменные(комплексные переменные) на основе класса которые могут хронить какие-то данные
