чтобы выводить сообщения для пользователя необходимо взаимодействовать с элементами интерфейса подобными элементами являеться страка статуса(статус бар) или специалное окно сообщений. 
В Qt по умолчанию доступен класс QMessageBox который позволяет создовать специпльное окно с предупреждениями, дополнительными информации, критическими ошибками и т.д.
для того чтобы использовать элементы qt(классы) их необходимо подключать(#include<QMessageBox>
базовые виды QMessageBox:
1. information - информация
2. worning - предупреждение
3. critical - создаёт окно кретической ошибки

У каждого окна есть специфический значоккоторый можно изменить.

Помимо основных окон есть и другие по типу about которые в qtcreator помечены отдельным значком

Нужно в авторизации чтобы при выводе неверного пароля вывод критикал или ворнинг кьюмесседж бокс

Работа с настройками.
Для работы с файлами настроек в qt есть специальный класс(Qsettings)
Позволяет создовать читать изменять ini файлы(.ini) 
Для создания или подключения файлов настроек надо при создании переменой или укателя(указать путь до файла, и указать  его формат(по умолчанию это константа QsettingsIniFormat))

как можно задовать значения по умолчанию все значения записываються в блок General. Чтобы задать значения нужен сетер(setValue) которому нужно передать ключ и значение
Все пары ключ\значение распределяется по блокам. По умолчанию блок General.
Создать блок или же группу можно при помощи метода Begin group (название группы)
и закончит блок методом endGroup

как считывать значения.

для того чтобы получить данные необходим использовать метод Value(название ключа, значение по умолчанию)
Чтобы получить коректный доступ к ключу нужно его прописывать следующим образом(Группа/Ключ)

Все значения полученные в результате работы метода value нуждаютсься в конвертации(.To<Тип данных>)
