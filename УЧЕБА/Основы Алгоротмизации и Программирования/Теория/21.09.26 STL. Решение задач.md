STL(Standart Template Lidrary(Стандартная библиотека шаблонов)) - для языка С++, которая предоставляет 3 основных компонента:
1. Контейнеры - Хранилище данных(vector(обычный динамический массив), list(упорядочный список), map, set())
2. Алгоритмы - функции для обработки данных (sort, transform, find, copy_if)
3. Наборы указателей(итераторов) - "умные" указатели для обходов контейнеров(vector.begin())
так как STL - являеться стандартной библиотекой, все обЪекты и классы внутри неё находяться в пространстве имён std, пример: std::vector
контейнер std::vector - динамический массив, который в отличии от обычного массива сам упровляет памятью и может изменять размер, для того чтобы использовать вектора необходим подключить vector
<vector> - системный файл 
"vector.cpp" - остальное
Итераторы - обьект который указывает на элемент контейнера(массива), некоторый курсор, например: итератор begin() указывает на начальный элемент, возвращает начальный элемент нашего массива, оператор end() указывает на последний+1
