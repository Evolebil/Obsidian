**==Модель==** - Оъьект, находящийся в определённом соответствии с изучаемым объект-оригиналом и способный замещать его при решении поставленных задач
1. Надо помнить:
	1. Модель всегда целевая - она строиться под конкретную задачу
	2. В модель попадают только существенные для цели свойство оригинала
	3. Модель - не копия: один объект может иметь много разных моделей

==**Моделирование**== - Метод познания и практической деятельности, состоящий в построении, исследовании и пременении моделей

Идея метода: Вместо непостредственного эксперемента с оригиналом, который может быть дорог, опасен, медленен или вообще не доступен, эксперемент проводят с его моделью, а результат переносят на оригинал

Цель моделирования: какие свойства включить в модель а какие отбросить как несущественные

2. ==**Цели моделирования:**==
	1. Понимание - как устроен обьект и каковы его наиболее важные характеристики
	2. Управление и прогнозирование - как обьект поведёт себя при разных воздействиях
	3. Оптимизация - поиск наилучших параметров обьекта или ражимов его работы
	4. Обучение и тренировака - Тренажёры для подготовки персонала
3. **==Требования к модели==**
	1. Адекатность - с заданной точностью воспроизводит свойства в пределах области применения
	2. Полнота - учитывает все существенные для цели факторы
	3. Простота - не содержит избыточных деталей, усложняющих иследование
	4. Гибкость - допускает изменение параметров и структуры 
	5. Вычислимость - позволяет получить ответ за приемлемое время
4. **==Класиффикация матем моделей==**:
	1. По области использование
		1. Учёба
		2. Опытные
		3. Научно - технические
		4. Игровые
		5. Имитационные
	2. По фактору времени
		1. Статическое - описывает объект в фиксированный момент времяни
		2. Динамический - Описывает развитии объекта во времени
	3. по форме представления
		1. Материальные - физический копии оригинала
		2. Информационные - информация об обьекте в виде описания
			1. Вербальное - слова
			2. Знаковое - письмо
				1. Матем
				2. Графическая
				3. Таблиц
	4. По учёту неопределённости
		1. Детерминированные - РЕзультат однозначно определяеться входными параметрами
		2. Стохатические - Учитывают случайные факторы
	5. По способу вычисления результата
		1. Аналитические - из формулы
		2. Имитационные - Многократно "проигрывают" поведение системы и статистически обрабатывают результаты
	6. По характеру изменения переменных 
		1. Непрерывные - любые значения из промежутка(1 - 100)
		2. Дискретные - точные исчелсяемые(1)
	7. По виду зависимости
		1. Линейные - линейные функции
		2. Нелинейные - модель "хищник жертва"
