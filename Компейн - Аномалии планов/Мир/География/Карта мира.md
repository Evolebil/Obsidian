# Карта мира

Карта мира 1208 года по слоям. Картинки — в папке `Карты`, скрипты и данные — `~/Documents/Проекты/DND_PRO/kampaniya/karty/`.

## Интерактивная карта
Файл `Карты/Интерактивная карта/index.html` — открыть в браузере (нужен интернет: библиотека Leaflet грузится с unpkg.com). Можно приближать; подписи меньших городов появляются по мере приближения, наезжающие прячутся. Слои включаются справа: государства, расы, людские наречия (одна из трёх основ), старые римские дороги и реки, главные пути, пути Акта I, города, ресурсы. Наведите на путь — длина в км; щёлкните по городу — население.
